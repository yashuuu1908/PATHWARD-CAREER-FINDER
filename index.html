Set up Google sign-in

One-time setup in your free Firebase project. Guests can keep using the app without this.

  1. Firebase console → Authentication → Get started → Sign-in method → turn on Google, Email/Password and (optional) Facebook. Facebook needs an App ID and secret from Meta for Developers.
  2. Authentication → Settings → Authorized domains → add the domain this app is hosted on (for example yourname.github.io).
  3. Project settings → Your apps → add a Web app → copy its firebaseConfig and paste it below.
  4. Realtime Database → Rules → make sure the pathward_users block below is in your rules, then Publish.
